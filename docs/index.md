# CPI-BGD Resource Library

Adapted **FHIR / HL7 / WHO / DHIS2** standards, CPI-branded templates, and system models for
Community Partners International (CPI) — Bangladesh Mission.

This public library is the shareable face of the CPI-BGD Resource Hub. Every page here is
written as text (Markdown, Mermaid, PlantUML) — versioned, diffable, and rebuildable.

## What is here

| Section | What you will find |
|---|---|
| Standards | How the HF-418 toolkit, HOP registers, and line lists map to FHIR/HL7/WHO/DHIS2 |
| Templates | The CPI-BGD template library manifest and naming rules |
| Models | The Health Operations Platform blueprint and the diagram color semantics |
| Glossary | Master glossary of every term and abbreviation used across the library |

## Principles

1. **Adapted, not invented** — mappings are confidence-stamped and sourced, never guessed.
2. **Diagram color semantics** — every diagram uses the CPI brand palette with a legend; color
   is never the only signal.
3. **Zero budget, Google-first** — everything here runs on free tiers and Google Workspace's
   nonprofit edition.
4. **No case data** — this library carries templates and standards, never patient-identifiable
   material.
