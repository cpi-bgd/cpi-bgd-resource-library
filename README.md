# cpi-bgd-resource-library

Public face of the CPI-BGD Resource Hub — adapted FHIR/HL7/WHO/DHIS2 standards, branded
templates, and system models for Community Partners International (CPI) — Bangladesh Mission.

**This repo is machine-composed.** Do not hand-edit content under `docs/`; it is regenerated
from the private hub repo (`cpi-bgd/cpi-bgd`) by `scripts/sync_public_library.py`. The MkDocs
of this repo is so configured to publish to GitHub Pages.
